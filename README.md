# АСУ-Оповещение (ASU-Notification)

Автоматизированная система уведомлений штабов — профессиональное решение для управления участниками и массовой рассылки SMS-уведомлений.

## Функциональность

- **Управление штабами**: Создание и переключение между различными штабами.
- **База участников**: Ведение списка участников с возможностью поиска, фильтрации и редактирования.
- **Рассылка SMS**: Отправка индивидуальных и массовых сообщений (интеграция с SMS API).
- **Дашборд**: Визуализация статистики и текущего статуса системы.
- **Безопасность**: Аутентификация операторов и разграничение прав доступа.

## Требования

- [Node.js](https://nodejs.org/) (версия 18.0.0 или выше)
- [npm](https://www.npmjs.com/) (обычно поставляется с Node.js)
- Аккаунт [Supabase](https://supabase.com/) для базы данных
- (Опционально) Доступ к SMS шлюзу (в текущей версии используется mock-сервис)

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd asu-notification
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка базы данных (Supabase)

1.  Создайте новый проект в Supabase.
2.  Перейдите в SQL Editor в панели управления Supabase.
3.  Скопируйте содержимое файла `supabase/schema.sql` из этого репозитория.
4.  Выполните SQL запрос для создания необходимых таблиц и политик безопасности.

### 4. Настройка переменных окружения

Создайте файл `.env` в корне проекта (можно скопировать пример, если есть, или создать новый) и добавьте следующие переменные:

```env
VITE_SUPABASE_URL=ваша_ссылка_на_проект_supabase
VITE_SUPABASE_ANON_KEY=ваш_anon_key_supabase
```

*Примечание: Если переменные не заданы, приложение будет работать в демонстрационном режиме с заглушками.*

### 5. Запуск в режиме разработки

Для запуска локального сервера разработки:

```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:5173`

### 6. Сборка для продакшена

Для создания оптимизированной сборки приложения:

```bash
npm run build
```

Файлы сборки появятся в папке `dist`. Для предпросмотра сборки можно использовать команду:

```bash
npm run preview
```

## Структура проекта

- `src/components` - Переиспользуемые компоненты UI
- `src/pages` - Страницы приложения (Dashboard, Staff, Messages)
- `src/context` - Управление глобальным состоянием (Auth, Staff)
- `src/services` - Сервисы для работы с API (Supabase, SMS)
- `src/types` - TypeScript интерфейсы
- `supabase` - SQL схемы и миграции базы данных

## Технологический стек

- React 18
- TypeScript
